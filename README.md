# 📊 International Education Enrollment Analysis (2016–2019)

- **Trend Analysis:** Multi-year longitudinal tracking (2016–2019) highlighting education level growth patterns[span_4](start_span)[span_4](end_span).
- **Dynamic Filtering:** Slicers implemented for interactive country-level and indicator-level data exploration[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span).
- **Data Transformations:** Handled via Power Query with tailored DAX logic for enrollment aggregations and percentage metrics[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).
