# 📊 Interactive Power BI Analytics Dashboard

An interactive multi-page Power BI dashboard designed to visualize, analyze, and extract key insights from complex datasets using advanced DAX measures, custom transformations, and dynamic filtering.

## 🌟 Key Features & Capabilities
- **Multi-Page Layout:** Structured views focusing on executive high-level KPIs and detailed analytical drill-downs.
- **Data Transformation:** Data cleaning, reshaping, and feature engineering implemented using **Power Query**.
- **Advanced DAX Metrics:** Custom calculated columns and dynamic measures for ratios, aggregations, and comparative trends.
- **Interactive Filtering:** Slicers and cross-filtering enabled for seamless exploratory data analysis.

## 🛠️ Tech Stack & Tools
- **Business Intelligence:** Power BI Desktop
- **Data Transformation:** Power Query (M Language)
- **Calculations & Logic:** DAX (Data Analysis Expressions)
- **Data Source:** Structured Datasets (Excel / CSV)
